Just the Fields – Templates

Quick start

  1. Download the starter template below.
  2. Edit it in any text editor (VS Code is great).
  3. In the app, go to Templates → Upload and pick your edited file.
  4. Select it from the Template dropdown (or use Auto (best match)).

Templates apply in Records mode. They do not apply in Dataset mode.
