Just the Fields – Templates

Quick start

  1. Download the starter template below.
  2. Edit it in any text editor (VS Code is great).
  3. In the app, go to Templates → Upload and pick your edited file.
  4. Select it from the Template dropdown (or use Auto (best match)).

Templates apply in Records mode. They do not apply in Dataset mode.

Notes:
• RFI, Submittal, Files, Issues, Change Items, Email, and Viewer Files templates depend on the export type. Plain and Combined exports require different templates.
• Viewer Files templates cover 3D models (IFC) and sheets viewed in the NFK Viewer created on or before Aug. 19, 2024. Files created after that date use the standard NFK – Files templates.
• If a template opens in your browser instead of downloading, use Right-click → Save As.
• For Change Items (Combined exports), Auto (best match) can reliably pick the Combined, all types template. Type-specific Combined templates (SI / PR / CP / CCD) are best used in Record mode when you want to force the type.
