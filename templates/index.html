Just the Fields – Templates

Quick start

  1. Download the starter template below.
  2. Edit it in any text editor (VS Code is great).
  3. In the app, go to Templates → Upload and pick your edited file.
  4. Select it from the Template dropdown (or use Auto (best match)).

Templates apply in Records mode. They do not apply in Dataset mode.

Each mock template corresponds to a dataset in /samples.

Notes:
• Mock templates correspond to the example datasets in the /samples folder and are intended for learning and testing.
• Plain and Combined exports have different data shapes and always require separate templates.
• If a template opens in your browser instead of downloading automatically, use Right-click → Save As.
• For Combined exports, Auto (best match) can reliably pick a general template. Type-specific Combined templates are best used in Record mode when you want to force the type.
